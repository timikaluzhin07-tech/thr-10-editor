# Перехват трафика официального THR Editor (USBPcap + Wireshark)

Нужен, если протокол из открытых источников окажется неточным, или чтобы
подтвердить команды со статусом `UNCONFIRMED` (Lamp, Wide, запись в ячейку).
Перехват только **читает** USB-трафик и ничего не отправляет на комбик.

## 1. Установка

1. Скачайте Wireshark для Windows с https://www.wireshark.org/download.html.
2. В установщике на шаге «Packet capture» отметьте **Install USBPcap**
   (или поставьте USBPcap отдельно с https://desowin.org/usbpcap/).
3. **Перезагрузите компьютер** — без этого USBPcap не видит устройства.

## 2. Какой USBPcap-интерфейс выбрать

1. Подключите THR10 и включите его.
2. Запустите Wireshark **от имени администратора**.
3. В списке интерфейсов есть `USBPcap1`, `USBPcap2`, … — это корневые
   USB-хабы. Нужен тот, к которому подключён комбик.
   * Нажмите на шестерёнку рядом с `USBPcapN`: в дереве устройств видно,
     есть ли там «THR10» / «Yamaha».
   * Если не ясно — запускайте по очереди: при правильном интерфейсе
     постоянно идут пакеты heartbeat (2 раза в секунду).
4. В настройках USBPcap можно оставить только комбик (галочка у устройства),
   чтобы в файл не попадали мышь и клавиатура.

## 3. Запись

1. Запустите захват на нужном `USBPcapN`.
2. Запустите официальный **THR Editor V1.1.0** и подождите, пока он
   подключится и прочитает состояние.
3. Делайте **по одному действию с паузой 3–5 секунд** и записывайте на бумаге
   порядок, например:
   1. Delay Time → 500 ms;
   2. Lamp выкл → вкл;
   3. Wide вкл → выкл;
   4. сохранить пресет в ячейку 2 (если эдитор так умеет);
   5. загрузить пресет из библиотеки эдитора.
4. Закройте THR Editor, остановите захват.
5. **File → Save As…** → формат `pcapng`, например `thr_capture.pcapng`.

Чтобы в Wireshark видеть только комбик: в начале записи найдите пакет
`GET DESCRIPTOR Response DEVICE` с `idVendor: Yamaha Corporation (0x0499)`,
посмотрите адрес устройства и примените фильтр (N — этот адрес):

```
usb.device_address == N && usb.transfer_type == 0x03
```

Скрипту разбора фильтр не нужен — он сам находит SysEx THR.

## 4. Разбор

```bat
py -3.12 tools\parse_capture.py thr_capture.pcapng --no-heartbeat
```

Скрипт:
* соберёт SysEx-сообщения из USB-пакетов (формат USB-MIDI, а если не
  подходит — «сырой» поток F0…F7);
* для каждого покажет время, направление (`ПК → комбик` / `комбик → ПК`),
  байты и расшифровку по протоколу редактора;
* пометит `!!` всё, что редактор не знает или не подтвердил;
* в конце — сводка: какие параметры менялись, сколько неизвестных сообщений.

Только неизвестное: `--only-unknown`. Отчёт в JSON: `--json report.json`.

Пример строки:

```
     12.481  ПК → комбик   delay.time = 5000  →  500 мс
                           F0 43 7D 10 41 30 01 31 27 08 F7
!!   20.112  ПК → комбик   системная команда 01 01 (lamp/wide по S1?)
                           F0 43 7D 30 41 30 01 01 F7
```

## 5. Что прислать

* `thr_capture.pcapng`;
* вывод `parse_capture.py` (или `--json`);
* список действий с порядком (из шага 3).

По этим данным команды подтверждаются в `docs/PROTOCOL.md`, а у вас —
через `protocol_overrides.json` (см. там же), без пересборки программы.
