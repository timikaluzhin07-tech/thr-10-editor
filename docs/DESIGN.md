# Дизайн-система «Studio Graphite»

Версия 1.1 (заменила первую, «Graphite & Glow»: та выглядела слишком
игрушечно — радужные дуги, «таблетки», плоские ручки, громкие кнопки).

## Направление

Редактор должен выглядеть как профессиональный студийный прибор: сдержанно,
точно, с вниманием к деталям. Ориентир — жанр студийных плагинов и
аппаратных процессоров, без копирования конкретного продукта.

Принципы:

1. **Один акцент.** Тёплый янтарь (отсылка к подсветке THR) — только для
   значения ручек, выбранного состояния, «LED» включённых блоков и одной
   главной кнопки на панели. Всё остальное — нейтральный графит.
2. **Цвет блока — шёпотом.** У каждого блока свой приглушённый оттенок, но
   он виден только в тонкой «риске» у края карточки, в списке рандомайзера и
   в LFO. Дуги ручек везде одного цвета.
3. **Глубина за счёт света, а не теней.** Лёгкие вертикальные градиенты
   поверхностей, однопиксельный блик по верхней кромке, «утопленные» поля
   ввода, объёмные ручки с фаской. Тени — только под лицевой частью ручки.
4. **Точность.** Тонкие линии (1 px), шкалы с рисками, табличные цифры,
   подписи капсом с разрядкой, скругления 4–9 px вместо «пузырей».
5. **Анимации подчёркивают изменения, а не украшают.** Короткие (110–420 мс),
   с замедлением в конце, ничего не мигает без причины.
6. **Один источник правды** — токены в
   [`thr10editor/ui/theme/tokens.json`](../thr10editor/ui/theme/tokens.json).
   В QML нет «магических» цветов и размеров.

## Токены

### Цвета

Обе темы содержат одинаковый набор ключей; тест `tests/test_theme.py`
проверяет это и контраст по WCAG.

| Токен | Назначение | Тёмная | Светлая |
|-------|-----------|--------|---------|
| `bg` / `bgGlow` | фон окна / едва заметное тёплое свечение сверху | `#0B0C0F` / янтарь 8 % | `#ECEDF0` / 8 % |
| `surface` / `surfaceTop` | карточки (градиент сверху вниз) | `#131519` / `#16181D` | `#F9FAFB` / `#FFFFFF` |
| `surface2` | дорожки переключателей, поля ввода | `#191C21` | `#F0F1F3` |
| `surface3` | приподнятое: выбранный сегмент, наведение | `#22262C` | `#E4E6E9` |
| `border` / `borderStrong` | разделители / рамки при наведении | `#23262C` / `#30343B` | `#DCDFE3` / `#C4C8CE` |
| `highlight` | блик по верхней кромке | белый 5 % | белый 70 % |
| `text` / `textMuted` / `textFaint` | основной / вторичный / подсказки | `#E8EAED` / `#9AA1AB` / `#6E757F` | `#16181C` / `#525863` / `#7B818B` |
| `accent` / `accentHover` / `accentText` | акцент и текст на нём | `#E9A23B` / `#F2B35A` / `#1A1206` | `#A0590E` / `#8A4C0B` / `#FFFFFF` |
| `accentSoft` / `glow` | подложка выбранного / свечение | | |
| `knobFaceTop` / `knobFaceBottom` | градиент лицевой части ручки | `#2B2F36` → `#15171B` | `#FFFFFF` → `#DCDFE3` |
| `knobBevel` / `knobRim` | фаска (свет сверху → тень снизу) | | |
| `knobTrack` / `knobTick` / `knobPointer` | дорожка дуги / риски шкалы / указатель | | |
| `groupAmp` … `groupGate` | приглушённые оттенки блоков | | |
| `success` `warning` `danger` `info` | статусы и «LED» связи | | |

Пороги контраста (тест): `text` ≥ 7:1, `textMuted` ≥ 4,5:1 на всех
поверхностях, `textFaint` ≥ 3:1, `accentText` на `accent` ≥ 4,5:1, акцент,
статусы и цвета групп ≥ 3:1.

### Типографика

Шрифт **Inter** (встроен, SIL OFL), табличные цифры (`tnum`) для значений.

| Токен | px | Где |
|-------|----|-----|
| `xs` 10.5 | подписи ручек и разделов капсом (разрядка 1.3) |
| `sm` 11.5 | значения ручек, вторичный текст, заголовки блоков капсом |
| `md` 13 | основной текст, кнопки |
| `lg` 14 | |
| `xl` 18 | имя звука, заголовки диалогов |
| `display` 36 | тап-темп |
| `stage` 88 / `stageSub` 26 | режим «Сцена» |

### Форма и размеры

* Отступы: 2–4–8–12–16–20–28–44.
* Скругления: `xs 3`, `sm 4` (чипы, поле значения), `md 6` (кнопки, поля,
  сегменты), `lg 9` (карточки), `xl 12` (диалоги, «Сцена»).
* Контрол 30 px; ручки 58 / 66 / 86 px; дуга 3 px.

### Движение

| Токен | мс | Где |
|-------|----|-----|
| `fast` | 110 | наведение, нажатие |
| `normal` | 180 | сдвиг индикаторов, смена вкладок |
| `slow` | 300 | свечение «LED», подъём сообщений |
| `value` | 160 | плавный поворот ручки при загрузке пресета, undo, A/B |
| `stagger` | 35 | задержка между карточками при появлении |
| `flash` | 650 | вспышка ручки, если значение пришло с комбика |
| `appear` | 420 | появление карточки |
| `theme` | 260 | смена темы |

## Анимации

Все короткие и подчёркивают изменение состояния:

* **Появление окна** — карточки усилителя и эффектов проявляются по очереди
  с подъёмом на 10 px.
* **Ручки** — плавно доворачиваются при загрузке пресета, undo, A/B и
  морфинге; при перетаскивании — без задержки. Значение с комбика → короткая
  вспышка свечения дуги (видно, что синхронизация сработала).
* **Включение блока** — рамка и значок кнопки питания плавно загораются,
  свечение «распускается».
* **Переключатели и вкладки** — индикатор и подчёркивание переезжают.
* **Имя звука и модель усилителя** — мягкая смена текста при загрузке.
* **Связь** — «LED» медленно дышит, пока комбик на связи.
* **Ожидание кнопки ячейки** — строка ячейки мягко пульсирует.
* **Тап-темп** — вспышка площадки на каждый удар.
* **Сообщения, выпадающие списки, диалоги** — проявление с лёгким подъёмом или
  масштабом 0,97–0,98 → 1.

## Раскладка

* **Верхняя панель**: знак, подпись «THR10 EDITOR» (с пометкой «изменено»),
  имя звука, связь, undo/redo, A/B, «Сцена», отправка, файлы, вид.
* **Слева** — библиотека / ячейки комбика / сет-листы (вкладки).
* **Центр** — усилитель и сетка эффектов (1–3 колонки по ширине).
* **Справа** — рандомайзер / морфинг / LFO / тап-темп.
* **«Сцена»** — крупное имя пресета на тёплом свечении, соседние пресеты.

## Как поменять стиль

1. Отредактируйте `thr10editor/ui/theme/tokens.json`.
2. `pytest tests/test_theme.py` — проверит ключи тем и контраст.
3. Перезапустите приложение. Иконку приложения можно перерисовать из токенов:
   `python tools/make_icon.py`.
