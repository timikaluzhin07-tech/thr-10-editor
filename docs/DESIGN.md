# Дизайн-система «Graphite & Glow»

## Направление

Редактор выглядит как современный студийный прибор, а не как скевоморфный
«кусок железа». Тёмная графитовая основа без чистого чёрного, глубина за
счёт ступеней светлоты поверхностей (почти без теней), **один тёплый
янтарный акцент** — отсылка к «ламповой» подсветке THR. У каждого блока
эффектов свой приглушённый оттенок: по цвету дуги ручки сразу видно,
какой это блок.

Принципы:

1. **Звук важнее интерфейса.** Ручки и значения крупные, хром — тихий.
   Акцент только там, где действие или активное состояние.
2. **Один источник правды.** Все цвета, шрифты, отступы, скругления, размеры
   и длительности анимаций — токены в
   [`thr10editor/ui/theme/tokens.json`](../thr10editor/ui/theme/tokens.json).
   В QML нет «магических» чисел и цветов.
3. **Плавно, но быстро.** Анимации 120–320 мс, `OutCubic`; смена темы —
   плавное перетекание цветов (260 мс). Ничего не анимируется дольше, чем
   нужно, чтобы глаз понял, что изменилось.
4. **Всё доступно с клавиатуры** и видно, где фокус (кольцо цвета `focus`).
5. **Масштабируемость.** Интерфейс адаптируется к размеру окна, HiDPI
   125–200 % обрабатывает Qt (без округления коэффициента), плюс
   пользовательский зум `Ctrl +` / `Ctrl −`.

## Токены

### Цвета

Обе темы содержат одинаковый набор ключей (проверяется тестом
`tests/test_theme.py`, там же проверяется контраст по WCAG).

| Токен | Назначение | Тёмная | Светлая |
|-------|-----------|--------|---------|
| `bg` | фон окна | `#0F1115` | `#F4F2EE` |
| `surface` | карточки, панели | `#171A21` | `#FFFFFF` |
| `surface2` | поля ввода, вложенные блоки | `#1E222B` | `#F1EEE8` |
| `surface3` | наведение, нажатие | `#272C37` | `#E7E3DB` |
| `border` / `borderStrong` | разделители / рамки элементов | `#2A2F3A` / `#3B4252` | `#E1DCD3` / `#C9C3B8` |
| `text` / `textMuted` / `textFaint` | основной / вторичный / подсказки | `#ECEEF3` / `#A4ABBA` / `#737B8C` | `#1C1F26` / `#555B69` / `#7E8492` |
| `accent` | действие, выбранное, фокус | `#FFB547` | `#A35E00` |
| `accentText` | текст на акценте | `#1C1305` | `#FFFFFF` |
| `accentSoft` | подложка выбранного | 15 % акцента | 12 % акцента |
| `success` `warning` `danger` `info` | статусы | | |
| `groupAmp` … `groupGate` | оттенки блоков: усилитель (янтарь), компрессор (бирюза), модуляция (фиолетовый), дилей (голубой), реверб (индиго), гейт (лайм) | | |
| `knobFace` `knobTrack` `knobPointer` | ручка | | |
| `overlay` `scrim` `shadow` | полноэкранный режим, затемнение под диалогом, тень | | |

Минимальный контраст (проверяется тестом):

* `text` на `bg`/`surface` ≥ 7:1, `textMuted` на `surface` ≥ 4,5:1;
* `accentText` на `accent` ≥ 4,5:1;
* акцент, статусы и цвета групп на `surface` ≥ 3:1 (графические элементы).

### Типографика

Шрифт **Inter** (встроен, лицензия SIL OFL, `thr10editor/ui/fonts/`) —
кириллица, табличные цифры (`tnum`) для значений ручек, чтобы числа не
«прыгали». Запасные: Segoe UI Variable → Segoe UI.

| Токен | px (при масштабе 1) | Где |
|-------|-----|-----|
| `xs` 11 | подписи-капсом (`letterSpacing.caps`), бейджи |
| `sm` 12 | подписи ручек, вторичный текст |
| `md` 14 | основной текст, кнопки |
| `lg` 16 | заголовки карточек |
| `xl` 20 | имя пресета |
| `xxl` 26 | заголовки диалогов |
| `display` 40 | крупные значения (тап-темп) |
| `stage` 88 / `stageSub` 28 | режим «сцена» |

Насыщенность: 400 / 500 / 600 / 700.

### Отступы, скругления, размеры

* Отступы — шкала 2–4–8–12–16–24–32–48 (`xxs`…`xxxl`).
* Скругления: `xs 4`, `sm 6`, `md 10` (кнопки, поля), `lg 14` (карточки),
  `xl 20` (диалоги), `pill` (чипы, переключатели).
* Размеры: контрол 32 px, ручка 76 px (малая 60, большая 100), толщина дуги 5.

### Движение

`fast 120` — наведение, нажатие; `normal 200` — появление элементов, смена
вкладок; `slow 320` — панели, режим «сцена»; `theme 260` — смена темы.

### Масштаб

`scale = clamp(min(w/1360, h/860), 0.8, 1.6)` с шагом 0,05, умноженный на
пользовательский зум (0,8–1,6). Все размерные токены отдаются в QML уже
умноженными на масштаб (`Theme.space.md`, `Theme.size.knob`…).

## Компоненты

| Компонент | Файл | Поведение |

## Раскладка

* **Верхняя панель**: имя пресета, индикатор связи, A/B, undo/redo,
  тап-темп, тема, «сцена», справка по клавишам.
* **Слева** — библиотека (поиск, папки, теги, избранное), ячейки комбика,
  сет-листы (вкладки). Сворачивается (`Ctrl+B`), на узком окне — выезжает.
* **Центр** — усилитель (крупные ручки) и сетка карточек эффектов, которая
  перестраивается по ширине (1–3 колонки).
* **Справа** — инструменты: рандомайзер, морфинг, автоматизация (LFO);
  сворачивается (`Ctrl+T`).
* **«Сцена»** (`F11`/`Ctrl+Enter`) — полноэкранный режим: огромное имя
  текущего пресета, следующий/предыдущий, номер в сет-листе.

## Как поменять стиль

1. Отредактируйте `thr10editor/ui/theme/tokens.json` (цвета обеих тем,
   шрифт, шкалы).
2. Запустите `pytest tests/test_theme.py` — тест проверит, что ключи тем
   совпадают и контраст не упал ниже порогов.
3. Перезапустите приложение. Код QML менять не нужно.
