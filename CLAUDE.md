# THR10 Editor — инструкции для Claude Code

Полное техническое задание: [docs/TASK.md](docs/TASK.md). Прочитай его перед началом работы.

Ключевые правила:
- Работай этапами из раздела «Порядок работы» и останавливайся после каждого, давая шаги проверки на реальном комбике.
- Не выдумывай байты SysEx: только подтверждённые источники или перехваченный трафик. Неподтверждённое помечай явно.
- На комбик отправляй только изменение параметров и чтение состояния, никаких команд прошивки/сброса.
- Слои: протокол → модель состояния → UI. Протокол не зависит от UI, покрыт тестами.
- Текущий этап и принятые решения записывай в docs/PROGRESS.md, чтобы новая сессия могла продолжить с того же места.
