# THR10 Editor — инструкции для Claude Code

Полное техническое задание: [docs/TASK.md](docs/TASK.md). Прочитай его перед началом работы.

Ключевые правила:
- Делай весь проект за один запуск: все этапы из раздела «Порядок работы» подряд, без остановок и без вопросов, если они не блокируют работу полностью. Спорные решения принимай сам и записывай в docs/PROGRESS.md.
- После каждого этапа: прогоняй тесты и делай коммит.
- Не выдумывай байты SysEx: только подтверждённые источники или перехваченный трафик. Неподтверждённое помечай явно и не отправляй на комбик.
- На комбик отправляй только изменение параметров и чтение состояния, никаких команд прошивки/сброса.
- Слои: протокол → модель состояния → UI. Протокол не зависит от UI, покрыт тестами. Приложение полностью работает в демо-режиме без комбика.
- Текущий этап и принятые решения веди в docs/PROGRESS.md, чтобы при обрыве сессии новая могла продолжить с того же места.
