# Готовые пресеты

Импорт: «Библиотека» → импорт файла (или перетащите файл в окно).

| Файл | Трек | Звук |
|------|------|------|
| `Спокойная ночь (Кино).thrpreset` / `Spokoynaya Noch.syx` | Кино — «Спокойная ночь» | чистый звонкий звук 80-х: Clean, US 2x12, лёгкий компрессор, хорус, короткий мягкий дилей 380 мс, Plate-реверб 2,4 с, мягкий гейт |

Темп дилея подстройте тап-темпом (клавиша **T**) под запись — 380 мс взяты как
стартовая точка. `.syx` — то же самое для других программ (имя латиницей:
в имени пресета на комбике кириллица не поддерживается).
